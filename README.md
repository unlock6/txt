# 녹음 파일 변환

PC에 있는 녹음 파일을 골라 **TXT로 저장하는 무료 프로그램**입니다. 한국어 통화 녹음을 위해 만들었으며, 녹음 재생 위치와 인식된 말을 표시합니다.

변환 중에 인식된 문장을 화면에서 차례로 볼 수 있고, 완료되면 녹음 파일과 같은 폴더에 TXT가 저장됩니다.

이 저장소는 **파일을 직접 선택하는 PC 버전**입니다. 구글 드라이브 연결이나 휴대폰 자동 녹음 기능은 포함하지 않습니다.

## 처음 사용하는 분: Windows 설치

Windows 64비트에서 **Python 3.12**를 사용하는 방법입니다. 현재 실행 파일(EXE)은 제공하지 않습니다.

1. [Python 공식 홈페이지](https://www.python.org/downloads/windows/)에서 **Python 3.12 Windows installer (64-bit)**를 설치합니다. 설치 항목의 Python launcher와 Tcl/Tk를 포함해 주세요.
2. 이 페이지 위의 **Code → Download ZIP**을 눌러 내려받고, 압축을 전부 풉니다.
3. 압축을 푼 폴더에서 **`install.cmd`**를 두 번 누릅니다. 인터넷 연결이 필요합니다. 마지막에 `Installation complete`가 나오면 설치가 끝난 것입니다.
4. 이후에는 같은 폴더의 **`run.cmd`**를 두 번 누르면 됩니다. 빠른 처리로 바로 열려면 `run-fast.cmd`를 사용합니다.

설치 담당자가 위 과정을 한 번 진행해 주시면, 사용하는 분은 `run.cmd`와 녹음 파일만 있으면 됩니다. 프로그램 폴더를 이동하거나 Python을 삭제했다면 다시 설치해 주세요.

## 녹음을 글자로 바꾸기

1. **파일 선택**을 누르고 변환할 파일을 고릅니다.
2. 음성 인식 모델을 고릅니다. `small`은 작은 모델, `turbo`는 큰 모델입니다. 녹음에 따라 결과와 속도가 달라지므로 같은 파일로 비교해 보세요.
3. 처리 방식에서 **기본 처리** 또는 **빠른 처리**를 고릅니다. 빠른 처리도 같은 모델을 사용하지만 결과와 메모리 사용량이 달라질 수 있습니다.
4. **텍스트로 변환**을 누릅니다. 처음에는 모델 다운로드 안내가 나옵니다. 동의하면 내려받고 변환을 시작합니다.
5. 완료 창이 뜨면 **저장 폴더 열기**를 누릅니다.

결과는 원래 녹음과 같은 폴더에 `녹음파일명.음성변환.txt`로 저장합니다. 같은 이름이 있으면 `-2`, `-3`을 붙여 새 파일을 만듭니다. 원본 녹음을 수정하거나 기존 TXT를 덮어쓰지 않습니다. 파일명에 전화번호가 있으면 결과 파일명에도 그대로 남습니다.

변환 중에는 PC와 프로그램을 켜 두세요. PC가 절전 상태에 들어가면 작업이 멈추거나 지연될 수 있습니다. 저장할 폴더에는 쓰기 권한이 있어야 합니다.

## 비용과 인터넷 사용

- 이 프로그램은 유료 API, 구독, API 키를 사용하지 않습니다. PC의 CPU로 변환합니다. 인터넷 통신료와 PC 운영 비용은 별도입니다.
- 설치 때 Python 패키지를, 첫 변환 때 Hugging Face에서 모델을 내려받습니다. `small`은 약 **0.49GB**, `turbo`는 약 **1.62GB**입니다. 설치 파일과 임시 다운로드를 위한 추가 여유 공간도 필요합니다.
- 필요한 모델을 준비한 뒤에는 인터넷 없이 변환할 수 있습니다. 모델을 삭제하거나 다른 모델을 선택하면 다시 다운로드해야 합니다.
- 앱은 녹음과 변환문을 외부 서버로 보내지 않습니다. 다운로드 서버에는 모델 파일 요청과 일반적인 접속 정보가 전달됩니다.
- 녹음을 OneDrive·Google Drive 등의 동기화 폴더에 두면 **그 동기화 프로그램의 설정에 따라** 원본과 TXT가 업로드될 수 있습니다.
- 모델은 Windows에서 기본적으로 `%LOCALAPPDATA%\RecordingToText`에 저장합니다. 앱은 종료 후에도 모델과 TXT를 보관합니다. 모델을 지우려면 프로그램을 닫은 뒤 해당 캐시 폴더를 삭제하세요.

## 변환 결과 확인

변환된 글은 대략적인 녹음 시각과 함께 표시됩니다. 표시 내용은 자동으로 인식한 말이며 실제 대화와 다를 수 있습니다. 원래 녹음을 들으며 내용을 확인해 주세요. 말소리가 전혀 인식되지 않으면 TXT를 만들지 않습니다.

## 문제 해결

| 상황 | 확인할 내용 |
| --- | --- |
| `install.cmd`에서 Python 설치 안내가 나옴 | Python 3.12 64비트, launcher, Tcl/Tk를 설치했는지 확인 |
| 모델 다운로드 실패 | 인터넷, 방화벽, 저장 공간을 확인하고 다시 변환. 인증서 검증을 끄지 마세요. 완료되지 않은 파일은 사용하지 않으며, 재시도하면 해당 파일을 처음부터 받습니다. |
| 빠른 처리에서 메모리가 부족하거나 오류가 남 | 기본 처리로 다시 시도. 녹음과 기존 TXT는 유지됩니다. |
| 변환이 느림 / 메모리 부족 | 다른 프로그램을 닫거나 작은 `small` 모델로 다시 시도 |
| TXT 저장 실패 | 녹음을 문서 등 쓰기 가능한 로컬 폴더로 복사한 뒤 다시 시도 |
| 글자가 실제 말과 다름 | TXT의 시각을 참고해 원본을 대조. 다른 모델로 비교해도 정확성을 보장하지 않습니다. |

지원 확장자: m4a, mp3, wav, amr, 3gp, 3ga, aac, ogg, flac, mp4. 손상된 파일이나 일부 코덱은 열리지 않을 수 있습니다. GPU는 필요하지 않습니다.

문제를 제보하려면 [Issues](https://github.com/unlock6/txt/issues)를 이용하세요. **실제 통화 파일, 전화번호가 들어간 파일명, 변환문, 연결키는 공개 이슈에 올리지 마세요.** 오류 문구와 운영체제·Python 버전만으로 먼저 설명해 주세요.

## 개발자용 실행

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install .
.venv\Scripts\python -m recording_to_text
```

명령행 변환: 모델이 없을 때만 `--download`가 필요합니다.

```powershell
.venv\Scripts\python -m recording_to_text "example.m4a" --model small --download
.venv\Scripts\python -m recording_to_text "example.m4a" --model turbo
.venv\Scripts\python -m recording_to_text --check --model small --download
```

기본 언어는 한국어이며, 영어는 `--language en`으로 지정합니다. 환경 변수 `RECORDING_TO_TEXT_HOME`으로 모델 캐시 위치를 바꿀 수 있습니다. 모델 저장소의 고정 revision, 파일 크기와 SHA-256은 패키지의 `models.json`에 있습니다. 모델을 읽기 전에 검증하며, 임의 경로나 API 키를 설정할 필요가 없습니다.

개발 테스트(모델 다운로드 없이 실행):

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
```

Python 3.12 / Windows / CPU int8에서 실제 음성 변환을 확인했습니다. 다른 OS의 GUI 동작은 확인하지 않았습니다. Windows 스크립트는 Python 3.12를 사용하며, 라이브러리의 Python 범위는 `pyproject.toml`에 명시했습니다. PyAV는 faster-whisper 1.2.1과의 호환성을 위해 16.1.0으로 고정했습니다. 새 버전으로 바꿀 때는 실제 파일 디코딩도 확인해 주세요.
